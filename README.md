### Анализ Транзакций
## Описание
Данное приложение предоставляет функциональность для анализа транзакций,находящихся в Excel-файле. Приложение генерирует JSON данные для веб-страниц,
формирует Excel отчеты, а также предоставляет другие сервисы, такие как выгоды по категории кешбэка, инвесткопилки и простые поиски транзакций.

## Использование
Запустите приложение, чтобы сгенерировать JSON-ответ вы можете использовать команду: python src/main.py
Приложение ожидает строку с датой и временем в формате YYYY-MM-DD HH:MM:SS. JSON-ответ будет выведен в консоль.
## Функциональность
- **Главная**: Формирует JSON-ответ с данными о расходах и приветствием в зависимости от времени суток.
### Сервисы
- **Простой поиск**: Позволяет искать по всем транзакциям.
### Отчеты
- **Траты по категории**: Анализ трат по категориям за указанный период.
